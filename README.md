## 🚀 Quick Start

### 📋 Prerequisites

Before you dive in, make sure you have these awesome tools installed:

- 📦 **Node.js** (v14 or higher) - For JavaScript magic
- 🌙 **Lua** (v5.1 or higher) - For scripting superpowers
- 💻 **Your favorite code editor** (VS Code recommended! 🎯)

### 🏗️ Installation

Getting started is super easy! Just follow these steps:

1. **Clone the repository** 📥
   ```bash
   git clone https://github.com/alexus37/test-public-repo.git
   cd test-public-repo
   ```

2. **Make files executable** ⚡
   ```bash
   chmod +x main.js
   chmod +x main.lua
   ```

3. **You're ready to go!** 🎉

## 🎮 Usage

### 🟨 JavaScript Components

Run the JavaScript magic:
```bash
node main.js
```

### 🌙 Lua Scripts

Execute Lua awesomeness:
```bash
lua main.lua
```

### 🔧 Handler Functions

The `handlers.lua` file contains powerful utility functions ready to be used in your projects!
